# SanaMatch — пакет для сдачи

## Что вставить в форму

**Название:** SanaMatch — от бизнес-задачи к студенческому проекту

**Описание:**

SanaMatch помогает бизнесу превратить короткое описание потребности в понятную задачу для студенческих команд. Диалоговый помощник задаёт уточняющие вопросы и предлагает факты с цитатами, которые бизнес подтверждает вручную. Редактируемая карточка получает прозрачный рейтинг готовности 0–100 и публикуется в общем каталоге с фильтрами. Команды отправляют идеи, планы и ссылки на прототипы; бизнес выбирает одну, несколько или ни одной команды. Баллы за прогресс начисляются отдельно после подтверждения выполненного этапа. Данные сохраняются в SQLite. Реализован серверный адаптер внешней модели и проверенный локальный fallback; живой LLM-вызов не подтверждён. Локальный режим представлен открыто, в соответствии с резервным вариантом из раздела 5 кейса.

**Репозиторий:** https://github.com/BAITC-Hacks/hack-17a0e36f-a7

**Публичная deployed-версия:** отсутствует. `localhost:4174` — адрес только на компьютере участницы, не публичная ссылка для жюри. В инструкции участников deployed-ссылка требуется только при её наличии.

## Как подать

1. Убедиться, что последняя версия кода отправлена в выданный организаторами репозиторий.
2. На платформе открыть трек «Образование» и выбранный кейс AI Sana Challenge Hub.
3. Нажать **«Сдать решение»**, вставить название и описание выше; указать репозиторий, если форма содержит это поле.
4. Проверить подтверждение отправки. Сам push в GitHub не является отправкой формы.
5. Сохранить подтверждение подачи и подготовиться показать сценарий из `DEMO.md` до 5 минут.

Форма автоматически не отправлялась: подача и её подтверждение остаются действием участницы.

## Запуск для жюри

Из корня клонированного репозитория:

```bash
python3 server/main.py --port 4174
```

Открыть http://localhost:4174. Нужен Python 3.9+, внешние зависимости не требуются. Без локального API-ключа работает явно обозначенный fallback. Рабочие секреты и база в репозиторий не входят.

Для отдельной репетиции на этом компьютере, без изменения рабочей базы и без вызовов внешней модели, запустить на свободном порту:

```bash
SANAMATCH_DB_PATH=server/data/rehearsal.sqlite3 AI_PROVIDER= AI_API_KEY= AI_MODEL= python3 server/main.py --port 4175
```

Существующий файл репетиции не сбрасывается. Не удаляйте рабочую базу ради нового показа.

## Что обязательно сказать честно

- Без API-ключа показан локальный помощник на правилах, не ответ внешней LLM. Условия кейса разрешают этот резервный вариант; промпт, контракт и обработка ошибок доступны в исходниках.
- Все начальные данные и демонстрационные подтверждения этапов синтетические.
- Нет авторизации и production-хостинга. Приложение предназначено для локальной демонстрации.
- Чат и неопубликованный черновик не сохраняются после перезагрузки; опубликованные задачи и отклики сохраняются.

## Организационные вопросы

- В PDF кейса указана команда 3–5 участников. Участница работает одна: разрешение на соло-участие нужно отдельно подтвердить у организаторов. Техническая готовность проекта сама по себе этого разрешения не даёт.
- По правилам зачёта последний час нужно находиться в зоне хакатона и нельзя уходить до официального завершения; индивидуальный допуск и присутствие здесь не проверялись.
- Конкретный дедлайн и подтверждение подачи нужно проверять на платформе/у организаторов. История коммитов сохраняется без изменения времени; прошедшие почасовые требования задним числом не восстанавливаются.
